# Luvann Ingeniería

Plataforma digital de Luvann Ingeniería para soluciones de optimización de procesos, análisis de datos, automatización e inteligencia artificial aplicada.

## Accesos permanentes

- Web corporativa: https://lukapablaza5-pixel.github.io/Luvann-web/
- Luvann FireOps V0.2: https://lukapablaza5-pixel.github.io/Luvann-web/fireops-demo.html
- Accesos rápidos: https://lukapablaza5-pixel.github.io/Luvann-web/accesos.html

## Proyecto destacado

**Luvann FireOps** es un prototipo demostrativo de digitalización del parte de asistencia y registro de emergencias, inspirado en un proceso real observado en Bomberos de Tomé. No constituye una implementación oficial ni una plataforma institucional del Cuerpo de Bomberos de Tomé.
